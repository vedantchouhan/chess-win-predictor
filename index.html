The Model

Features a robust Gradient Boosting Classifier implemented via Scikit-Learn. Trained entirely on 3,827 curated Lichess matches to evaluate positionless pre-game parameters before the first move is ever played.

Architecture

The frontend is a vanilla JS application utilizing lightweight glassmorphic CSS, interfacing dynamically with a Python FastAPI backend to guarantee sub-50ms model inference latency.

Evaluation Metrics

Achieved 77.4% true test accuracy on holdout data. The algorithm is heavily optimized to minimize false positives on upsets, heavily weighting Elo differentials against chosen time controls.

Deployment

The Python ML inference engine is packaged into a stateless API layer. This allows for seamless, instantaneous deployment to cloud platforms like Azure App Service or Render with zero cold-start delay.
